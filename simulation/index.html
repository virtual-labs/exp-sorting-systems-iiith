Instructions

Learn how to use the MapReduce Distributed Sort Simulator

Interactive Controls

  • Configure Parameters: Set number of mappers (2-6), reducers (≤ mappers+1), and partition strategy.
  • Load Data: Initialize simulation with your input data (comma-separated numbers).
  • Step Through: Use "Next Step" to progress through each MapReduce phase individually.
  • Auto Run: Automatic progression through all phases with visual feedback.
  • Pause/Reset: Control simulation flow and restart with different parameters.

Simulation Metrics

  • Data Distribution: Visual representation of how data is distributed across mappers.
  • Processing Progress: Real-time tracking of sort operations and data movement.
  • Performance Statistics: Monitor successful sorts, elements processed, and communication rounds.

MapReduce Phases

  • Map Phase: Input data distributed across mapper nodes for parallel processing.
  • Shuffle Phase: Data reorganized and grouped by partition keys (Hash/Range).
  • Reduce Phase: Each reducer independently sorts its assigned data partition.
  • Final Merge: Sorted partitions combined into final sorted output.

Learning Objectives

  • Understand distributed sorting principles and MapReduce framework benefits.
  • Compare Hash vs Range partitioning strategies for data distribution.
  • Observe parallel processing impact on sorting large datasets efficiently.
  • Analyze the relationship between mappers, reducers, and overall performance.

Distributed Sort Instructions

Overview

This simulation demonstrates how MapReduce framework performs distributed sorting of large datasets across multiple machines.

How to Use

  1. Configure Parameters: Set the number of mappers, reducers (≤ mappers+1), and partition strategy
  2. Input Data: Enter comma-separated numbers or use the default dataset
  3. Load Data: Click "Load Data" to initialize the simulation
  4. Step Through: Use "Next Step" to see each phase individually
  5. Auto Run: Click "Auto Run" for automatic progression through all phases
  6. Reset: Clear the simulation and start over with new parameters

MapReduce Phases

  • Map Phase: Input data is distributed across mapper nodes
  • Shuffle Phase: Data is reorganized and grouped by partition keys
  • Reduce Phase: Each reducer sorts its assigned data partition
  • Merge Phase: Sorted partitions are merged into final sorted output

Partition Strategies

  • Hash Partitioning: Uses hash function for even data distribution
  • Range Partitioning: Divides data into sorted ranges

Key Benefits

  • Parallel processing reduces overall sorting time
  • Scalable to handle very large datasets
  • Fault-tolerant with automatic recovery
  • Efficient network utilization during shuffle phase
